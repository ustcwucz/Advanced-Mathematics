# 微分方程

## 基本概念

- **阶**：方程中最高阶导数的阶数
- **线性**：未知函数 $y$ 及其各阶导数都是一次的
- **齐次**：方程右端项为零
- **通解**：包含独立任意常数个数等于方程阶数的解
- **特解**：不含任意常数的解

---

## 解的性质和结构

### 线性微分方程

未知函数 $y$ 及其各阶导数项次数都是 1

### 叠加原理

- 若 $y_1, y_2$ 是齐次线性方程 $L[y]=0$ 的解，则 $C_1y_1 + C_2y_2$ 也是解
- 非齐次线性方程的通解 = 对应齐次通解 + 一个特解

### 解的结构

- **$n$ 阶齐次线性微分方程有且仅有 $n$ 个线性无关的解**
- 通解：$y = C_1y_1 + C_2y_2 + \cdots + C_ny_n$
- 非齐次通解：$y = Y + y^*$（$Y$ 为齐次通解，$y^*$ 为非齐次特解）

## 一阶微分方程

### A. 可分离变量

$$\frac{dy}{dx} = f(x)g(y) \Rightarrow \int \frac{dy}{g(y)} = \int f(x)dx$$

### B. 一阶线性非齐次

$$\frac{dy}{dx} + P(x)y = Q(x)$$
**通解**：
$$y = e^{-\int P(x)dx}\left[\int e^{\int P(x)dx}Q(x)dx + C\right]$$

**来源**：常数变易法
先解齐次：$y_0 = Ce^{-\int P(x)dx}$
设 $y = C(x)e^{-\int P(x)dx}$，回代得 $C(x) = \int e^{\int P(x)dx}Q(x)dx + C$

### C. 分段函数

- **法一**：分区间分别套通解公式，用交界点处的连续、可导或方程本身联系各段常数
- **法二**：直接套通解，求积分时分段算

### D. 可换元

#### 1. $\frac{y}{x} = u$（齐次方程）

$$y = xu \Rightarrow \frac{dy}{dx} = u + x\frac{du}{dx}$$

#### 2. $ax + by = u$

$$y = \frac{u - ax}{b} \Rightarrow \frac{dy}{dx} = \frac{1}{b}\frac{du}{dx} - \frac{a}{b}$$

#### 3. 伯努利方程

$$\frac{dy}{dx} + P(x)y = Q(x)y^n \quad (n \ne 0,1)$$
令 $z = y^{1-n}$，转化为一阶线性方程

#### 4. $yy' = (y^2)'/2$

#### 5. $\cos y \cdot y' = (\sin y)'$，$\sec^2 y \cdot y' = (\tan y)'$

### E. 恰当方程

$$M(x,y)dx + N(x,y)dy = 0$$
若 $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$，则存在 $u(x,y)$ 使 $du = Mdx + Ndy = 0$
解为 $u(x,y) = C$

**求 $u$ 的方法**：
$$u(x,y) = \int_{x_0}^x M(x,y_0)dx + \int_{y_0}^y N(x,y)dy$$

### F. 特殊

看成 $x$ 关于 $y$ 的方程，解得 $x = f(y)$ 求反函数

## 二阶微分方程

### A. 二阶常系数齐次

$$y'' + py' + qy = 0$$
特征方程：$r^2 + pr + q = 0$

| 特征根情况               | 通解形式                                            |
| ------------------------ | --------------------------------------------------- |
| $r_1 \ne r_2$（实根）    | $y = C_1e^{r_1x} + C_2e^{r_2x}$                     |
| $r_1 = r_2 = r$          | $y = (C_1 + C_2x)e^{rx}$                            |
| $r = \alpha \pm \beta i$ | $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |

### B. 二阶常系数非齐次

$$y'' + py' + qy = f(x)$$

**特解形式**（待定系数法）：

| $f(x)$ 形式                                                  | 特解形式                                                  |
| ------------------------------------------------------------ | --------------------------------------------------------- |
| $P_m(x)$                                                     | $x^k Q_m(x)$                                              |
| $P_m(x)e^{\alpha x}$                                         | $x^k Q_m(x)e^{\alpha x}$                                  |
| $P_m(x)e^{\alpha x}\cos\beta x$ 或 $P_m(x)e^{\alpha x}\sin\beta x$ | $x^k e^{\alpha x}[Q_m(x)\cos\beta x + R_m(x)\sin\beta x]$ |

其中 $k$ 为 $\alpha$（或 $\alpha \pm \beta i$）作为特征根的重数

**关键**：猜特解形式，待定系数

### C. 非齐次项为分段函数

分区间求通解，交界处连续且一阶导数连续

### D. 含参数讨论

根据参数取值分类讨论

### E. 二阶变系数

#### 1. 可降阶

- $y'' = f(x)$：直接积分两次
- $y'' = f(x, y')$：令 $p = y'$，$p' = y''$
- $y'' = f(y, y')$：令 $p = y'$，$y'' = p\frac{dp}{dy}$

#### 2. 欧拉方程

$$ax^2y'' + bxy' + cy = f(x)$$
令 $x = e^t$（$x>0$），则 $xy' = Dy$，$x^2y'' = D(D-1)y$，其中 $D = \frac{d}{dt}$
化为常系数方程求解，再换回
